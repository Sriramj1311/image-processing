🔬 IMAGE  PROCESSING

An interactive web-based **Image Processing** developed to demonstrate fundamental image-processing techniques through a simple and user-friendly interface.

The project allows users to upload an image, apply different filters and edge-detection operators, view the selected kernel, and observe the processed output.

 🌐 Live Demo

(https://sriramj1311.github.io/image-processing/)**

 ✨ Key Features

- 🖼️ **Image Upload** – Upload and preview an image.
- ⚫ **Grayscale Processing** – Convert images into grayscale.
- 🌫️ **Mean Filter** – Smooth images using a 3×3 averaging kernel.
- ✨ **Gaussian Filter** – Apply Gaussian smoothing.
- 📐 **Sobel Operator** – Detect horizontal and vertical edges.
- 🔲 **Laplacian Operator** – Detect edges based on intensity changes.

🎯 Objective

The main objective of this project is to provide a visual and interactive way to understand **image filtering, convolution, kernels, grayscale processing, and edge detection**.

🔬 Operators
1. Mean Filter

The Mean Filter smooths an image by calculating the average value of neighboring pixels.
It is mainly used for image smoothing and reducing small variations or noise.

2. Gaussian Filter

The Gaussian Filter performs smoothing by giving more importance to pixels near the center of the kernel.
It is commonly used for noise reduction and image preprocessing.

3. Sobel Operator

The Sobel Operator detects edges by calculating changes in pixel intensity.
It provides two directions:
Sobel X – Detects vertical edges.
Sobel Y – Detects horizontal edges.
The Sobel operator is useful for edge detection and identifying object boundaries.

4. Laplacian Operator

The Laplacian Operator detects rapid changes in image intensity.
It is mainly used for edge detection and highlighting boundaries in an image.

🔢 Pixel Visualization

The application provides a visual representation of image pixel values.

Users can:

View grayscale pixel values.
Observe the processed pixel values.
Understand how a 3×3 kernel affects neighboring pixels.
View the kernel used by the selected operator.
Compare the input and processed images.

This helps users understand the convolution process and how image filters modify individual pixels.
